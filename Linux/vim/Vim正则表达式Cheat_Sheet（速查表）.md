# 📘 Vim 正则表达式 Cheat Sheet（速查表）

## 一、Magic 模式对照表（关键符号行为）

| 功能 / 符号       | 默认模式  | `\m` (magic) | `\v` (very magic) | `\M` (nomagic) | `\V` (very nomagic) |
| ----------------- | --------- | ------------ | ----------------- | -------------- | ------------------- |
| **行首** `^`      | ✅ 特殊    | ✅ 特殊       | ✅ 特殊            | ✅ 特殊         | ❌ 字面              |
| **行尾** `$`      | ✅ 特殊    | ✅ 特殊       | ✅ 特殊            | ✅ 特殊         | ❌ 字面              |
| **任意字符** `.`  | ✅ 特殊    | ✅ 特殊       | ✅ 特殊            | ❌ 字面         | ❌ 字面              |
| **0+ 次** `*`     | ✅ 特殊    | ✅ 特殊       | ✅ 特殊            | ❌ 字面         | ❌ 字面              |
| **1+ 次** `+`     | ❌ 字面    | ✅ 特殊       | ✅ 特殊            | ❌ 字面         | ❌ 字面              |
| **0/1 次** `?`    | ❌ 字面    | ✅ 特殊       | ✅ 特殊            | ❌ 字面         | ❌ 字面              |
| **分组** `( )`    | ❌ 字面    | ✅ 特殊       | ✅ 特殊            | ❌ 字面         | ❌ 字面              |
| **或** `\|` / `|` | `\|` 特殊 | `\|` 特殊    | `|` 特殊          | `\|` 字面      | `\|` 字面           |
| **字符集** `[ ]`  | ✅ 特殊    | ✅ 特殊       | ✅ 特殊            | ✅ 特殊         | ✅ 特殊              |
| **量词** `{n,m}`  | `\{n,m\}` | `\{n,m\}`    | `{n,m}`           | `\{n,m\}` 字面 | `{n,m}` 字面        |
| **反斜杠** `\`    | ✅ 特殊    | ✅ 特殊       | ✅ 特殊            | ✅ 特殊         | ✅ 特殊              |

> ✅ = 特殊含义（需转义才字面）  
> ❌ = 字面字符（需加 `\` 才有特殊含义，或根本不支持）  
> ⚠️ **注意**：`[ ]` 在所有模式下都用于字符集，无法关闭！

## 二、常用语法速查

### 1. 位置锚点
| 模式 | 含义                       |
| ---- | -------------------------- |
| `^`  | 行首（除 `\V` 外始终有效） |
| `$`  | 行尾（除 `\V` 外始终有效） |
| `\<` | 单词开头（Vim 特有）       |
| `\>` | 单词结尾（Vim 特有）       |

### 2. 分组与引用
| 模式                   | 分组        | 引用                  |
| ---------------------- | ----------- | --------------------- |
| 默认                   | `\( ... \)` | `\1`, `\2`, ..., `\9` |
| `\v`                   | `( ... )`   | `\1`, `\2`, ..., `\9` |
| 非捕获分组（所有模式） | `\%(...\)`  | 不可引用              |

### 3. 字符类简写（所有模式通用）
| 简写 | 含义                    |
| ---- | ----------------------- |
| `\d` | 数字 `[0-9]`            |
| `\D` | 非数字                  |
| `\s` | 空白（空格、Tab）       |
| `\S` | 非空白                  |
| `\w` | 单词字符 `[0-9A-Za-z_]` |
| `\W` | 非单词字符              |
| `\x` | 十六进制数字            |
| `\h` | 十六进制数字 + `a-fA-F` |

> 💡 提示：`\d` 比 `[0-9]` 更快（尤其在旧引擎中）

### 4. 替换专用符号
| 符号        | 含义                         |
| ----------- | ---------------------------- |
| `&` 或 `\0` | 整个匹配内容                 |
| `\1`–`\9`   | 第1–9个分组                  |
| `~`         | 上次替换内容（在替换命令中） |
| `\r`        | 插入换行（在替换内容中）     |

## 三、实用示例

| 需求                           | 命令                        |
| ------------------------------ | --------------------------- |
| 全文替换 `foo` → `bar`         | `:%s/foo/bar/g`             |
| 交换 `key=value` → `value=key` | `:%s/\v(\w+)=(\w+)/\2=\1/g` |
| 删除行尾空格                   | `:%s/\s\+$//`               |
| 高亮超过 80 列的内容           | `:match Error /\%>80v.\+/`  |
| 匹配字面 `[abc]`               | `:%s/\[abc\]/REPL/g`        |
| 在 `\M` 模式下匹配行首 `TODO`  | `:%s/\M^TODO/FIXED/g`       |

---

## 四、最佳实践建议

- ✅ **复杂正则用 `\v`**：减少转义，接近通用正则。
- ✅ **简单文本用默认或 `\M`**：避免意外匹配。
- ✅ **测试先高亮**：`:set hlsearch` + `/pattern` 验证。
- ✅ **不确定就加 `c`**：`:%s/.../.../gc` 逐个确认。
- ❌ **不要用 `$1`**：Vim 用 `\1` 引用分组。
