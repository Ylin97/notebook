# Vim 正则表达式使用指南

Vim 的正则表达式用法灵活但有其特殊性，核心在于对「特殊字符」的处理规则随模式不同而变化。以下是总结的核心用法和注意事项：

---

## 一、正则模式分类（核心区别）

Vim 正则的核心特点是通过**模式标记**控制字符的「特殊含义」，常用模式有 4 种：

| 模式标记 | 名称         | 特殊字符范围（需转义才能表示字面）                           | 适用场景                     |
| -------- | ------------ | ------------------------------------------------------------ | ---------------------------- |
| 无标记   | 默认模式     | `^ $ . * \` 是特殊字符；`+ ? ( ) | { }` 等按字面处理         | 简单匹配，减少转义           |
| `\m`     | magic 模式   | `^ $ . * + ? ( ) [ ] \| { }` 是特殊字符（注意：`[` `]` 在所有模式下都特殊） | 中等复杂度正则，常用分组/或  |
| `\v`     | very magic   | 几乎所有标点（含 `+ ? ( ) [ ] \| { }` 等）均为特殊字符，接近通用正则 | 复杂正则（分组、量词等）     |
| `\M`     | nomagic 模式 | **`^ $ \` 是特殊字符**；其余（包括 `. * + ? ( ) [ ] \| { }`）均按字面处理<br>（⚠️ 但 `[]` 仍用于字符集） | 纯文本匹配，避免特殊字符干扰 |

> 📌 **重要说明**：
> - **`[` 和 `]` 在所有模式下都是特殊字符**，用于定义字符集（如 `[abc]`），**无法通过 magic 模式关闭其特殊性**。若要匹配字面 `[` 或 `]`，必须写成 `\[` 或 `\]`。
> - **`\M` 模式下 `^` 和 `$` 依然有效**，分别匹配行首和行尾。

**模式启用方式**：在替换命令的匹配规则**开头**添加标记，例如：
```vim
:%s/\v(a)-(b)/\2-\1/g   " 启用 \v 模式
:%s/\M^foo/bar/         " 启用 \M 模式，^ 仍匹配行首
```

## 二、核心语法（通用正则功能）

### 1. 字符匹配
- `.`：匹配任意单个字符（默认模式及以上生效；`\v` 中需转义 `\.` 才表示字面点）。
- `[abc]`：匹配 `a`/`b`/`c` 中的任意一个（**所有模式下 `[]` 都是字符集语法**）。
- `[^abc]`：匹配除 `a`/`b`/`c` 外的任意字符（反向字符集）。

### 2. 量词（重复匹配）
- `*`：匹配前一个字符 0 次或多次（默认模式及以上生效）。
- `+`：匹配前一个字符 1 次或多次（`\m`/`\v` 模式直接用；默认模式需写 `\+`）。
- `?`：匹配前一个字符 0 次或 1 次（`\m`/`\v` 模式直接用；默认模式需写 `\?`）。
- `{n,m}`：匹配前一个字符 `n` 到 `m` 次  
  - `\v` 模式：直接写 `{n,m}`（必须紧贴前一个原子，如 `a{2}`）  
  - `\m` 模式：需转义为 `\{n,m\}`  
  - 默认模式：需转义为 `\{n,m\}`

### 3. 分组与引用
- `(pattern)`：定义分组  
  - `\v`/`\m` 模式：直接用 `( )`  
  - 默认模式：需写 `\(pattern\)`
- `\1`/`\2`：在替换内容中引用第 1/2 个分组（Vim 用 `\1`，**不是 `$1`**）

### 4. 位置匹配
- `^`：匹配行首（**所有模式下都有效**）
- `$`：匹配行尾（**所有模式下都有效**）
- `\<` / `\>`：匹配单词的开头/结尾（Vim 扩展，如 `\<word\>` 匹配完整单词）

### 5. 或逻辑
- `a\|b`：匹配 `a` 或 `b`  
  - `\v`/`\m` 模式：直接写 `a|b`  
  - 默认模式：需写 `a\|b`

## 三、替换命令格式

基础格式：`:[范围]s/匹配规则/替换内容/[选项]`

- **范围**：`%`（全文）、`n,m`（第 n 到 m 行）、`.`（当前行）等。
- **选项**：
  - `g`：全局替换（一行内所有匹配）
  - `c`：逐个确认替换（`y`/`n`/`q`）
  - `i`：忽略大小写
- **分隔符**：可改用 `#`、`@` 等避免 `/` 转义，例如：
  ```vim
  :%s#http://#https://#g
  ```

---

## 四、注意事项

1. **转义规则随模式变化**  
   - 例如 `()` 在默认模式是普通字符，在 `\v` 中是分组符号。  
   - **推荐**：简单场景用默认模式，复杂正则用 `\v`（语法接近通用正则，减少转义负担）。

2. **分组引用用 `\1`，不是 `$1`**  
   Vim 替换中引用分组始终使用 `\1`、`\2`……

3. **替换内容中的特殊符号**  
   - `&` 表示整个匹配内容，如 `:%s/abc/[&]/g` → `[abc]`  
   - `\0` 等价于 `&`  
   - 要输入字面反斜杠，写 `\\`

4. **大小写敏感**  
   默认区分大小写；加 `i` 选项忽略，如 `:%s/abc/xyz/gi`

5. **测试与确认**  
   - 开启 `:set hlsearch` 高亮匹配内容  
   - 复杂替换加 `c` 选项逐个确认

---

## 五、示例总结

- 替换全文 `(2)` 为 ` 2`（默认模式，`()` 是普通字符）：  
  ```vim
  :%s/(2)/ 2/g
  ```

- 交换 `a-b` 为 `b-a`（使用 `\v` 模式）：  
  ```vim
  :%s/\v(a)-(b)/\2-\1/g
  ```

- 匹配字面 `file.txt`（转义 `.`）：  
  ```vim
  :%s/file\.txt/doc.txt/g        " 默认模式
  :%s/\vfile\.txt/doc.txt/g      " \v 模式（. 仍需转义）
  ```

- 在 `\M` 模式下匹配行首 `foo`：  
  ```vim
  :%s/\M^foo/bar/g   " ^ 仍然有效！
  ```

- 匹配字面 `[abc]`（注意 `[]` 始终特殊）：  
  ```vim
  :%s/\[abc\]/REPL/g   " 所有模式下都需转义
  ```
